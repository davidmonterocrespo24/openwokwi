SSD1306 monochrome OLED (128×64). Talks **I²C or SPI** — pick with the
`protocol` property. Drive it with Adafruit_SSD1306 or U8g2.

| Pin (I²C) | Role |
| --- | --- |
| VCC | 3.3–5 V |
| GND | ground |
| SCL | I²C clock |
| SDA | I²C data |

- Default I²C address **0x3C**.
- 128×64 pixels, ~1 KB framebuffer, self-emitting (no backlight).

**Tip:** switch `protocol` to `spi` to expose the SCK / MOSI / DC / CS / RES pins.
