SSD1306 monochrome OLED (128×64) on the **Adafruit-style breakout**, which
brings the controller's full pinout out to a 9-way header. Talks **I²C or
SPI** — pick with the `protocol` property. Drive it with Adafruit_SSD1306 or
U8g2.

| Pin | I²C role | SPI role |
| --- | --- | --- |
| Vin | 3.3–5 V | 3.3–5 V |
| 3v3 | 3.3 V regulator output | 3.3 V regulator output |
| Gnd | ground | ground |
| Data | SDA (data) | MOSI |
| Clk | SCL (clock) | SCK |
| SA0 | address select (0x3C / 0x3D) | — |
| DC | — | data/command |
| CS | — | chip select |
| Rst | reset (optional) | reset (optional) |

- Default I²C address **0x3C**.
- 128×64 pixels, ~1 KB framebuffer, self-emitting (no backlight).

**Tip:** switch `protocol` to `spi` to drive it over SPI. If you only need
I²C and want the plain 4-wire module, use the **SSD1306 OLED (I2C, 4-pin)**
part instead.
