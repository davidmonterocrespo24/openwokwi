DHT22 (AM2302) temperature + humidity sensor on a single-wire digital bus.
One reading every ~2 s; use the Adafruit DHT or DHTNEW library.

| Pin | Role |
| --- | --- |
| VCC | 3.3–5 V supply |
| DATA | single-wire data (needs pull-up) |
| GND | ground |

- Temperature **−40 to +80 °C**, ±0.5 °C.
- Humidity **0–100 % RH**, ±2–5 %.

**Tip:** add a **10 kΩ pull-up** from DATA to VCC; poll no faster than 0.5 Hz.
